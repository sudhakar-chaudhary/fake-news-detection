# Fake News Detection

## Project Overview
This project uses Natural Language Processing and Machine Learning
to classify news articles as Real or Fake.

## Technologies Used
- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn
- NLP
- TF-IDF

## Workflow
News Input
     ↓
Text Preprocessing
     ↓
TF-IDF Vectorization
     ↓
Machine Learning Model
     ↓
Real / Fake Prediction

## Model
Machine Learning classification model trained on a news dataset.

## How to Run
1. Install requirements
2. Open the notebook
3. Run the cells
4. Enter news text
5. Get prediction
